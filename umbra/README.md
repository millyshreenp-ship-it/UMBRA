# UMBRA Delhi
npm install && npm run dev
MapLibre (OpenFreeMap, 3D buildings) + Deck.gl shadow layer + Nominatim bounded to Delhi.
13 crowded Delhi places, 43 hidden nodes. All numbers are simulated demo data; coordinates are approximate.
Screens: Map, Evacuate (fire, flood, power cut, crowd surge, routes, signage), Ask, Report (dots and text parser), Insights (early warning, cost vs impact, PDF brief).
Map extras: time slider, heatmap, flow particles, dependency % on arcs, fragility tags, multi-node closing, before/after, cascade tree, confirm/reject.
